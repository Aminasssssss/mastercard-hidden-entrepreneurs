# Model Card — Hidden Entrepreneur Detector v1.0

## Описание

One-class ансамбль для обнаружения скрытых предпринимателей среди держателей потребительских карт по транзакционному поведению за 6 месяцев.

## Назначение

- **Выход:** скор от 0 до 1 на каждую потребительскую карту.
- **Использование:** cross-sell. Топ-карты по скору попадают в outreach с предложением перехода на бизнес-тариф.
- **Не используется** для отказа в обслуживании или ограничений.

## Архитектура

- **Тип:** one-class novelty detection
- **Метод:** rank-average ensemble из 6 моделей
- **Компоненты:**
  1. Isolation Forest (n_estimators=300)
  2. One-Class SVM (RBF, nu=0.1, train на 5К сэмплов)
  3. Gaussian Mixture (5 компонент, full covariance)
  4. Mahalanobis distance (regularized)
  5. Autoencoder (MLP 16-8-16, sklearn)
  6. PU Learning (Elkan–Noto, LightGBM)
- **Веса:** равные (1/6)

## Данные

- **Train:** 25 000 бизнес-карт × 3 млн транзакций
- **Apply:** 80 000 потребительских карт × 9.8 млн транзакций
- **Период:** 6 месяцев (окт 2025 — мар 2026)
- **Источник:** синтетика Mastercard Data Quest 2026
- **Гранулярность:** одна строка = одна карта (агрегаты за период)

## Метрики

| Метрика | Значение | Замечание |
|---|---|---|
| Pseudo-AUC (biz vs cons) | ~1.0 | Вырождена на синтетике |
| Top-100 B2B-ratio | ~0.65 | vs ~0.02 у обычных |
| Top-100 lift | ×30+ | По бизнес-признакам |
| Robustness (3 seeds) | 85% | Пересечение топ-100 |

## Ограничения

- Pseudo-AUC вырожден на синтетике; для тюнинга весов не используется.
- Поведенческая валидация — прокси, не эквивалент истинных меток.
- Граф-фичи избыточны с MCC (Spearman 0.71–0.87, 0/800 эксклюзивных).
- PU Learning требует SCAR (Selected Completely At Random).
- Один скор на карту, не на клиента. Identity resolution не реализована.

## Этика

- Только агрегаты по транзакциям, без ПДн.
- Скоринг для cross-sell, не для отказа/ограничений.
- Ложноположительные результаты не вредят клиенту.
